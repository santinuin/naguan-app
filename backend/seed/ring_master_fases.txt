# Calentamiento y movilidad de Ring Master. A diferencia de Unbreakable, no es una
# transcripción: la app original los tenía pero se perdieron al cerrar. Es una
# reconstrucción propia (por eso se versiona), con ejercicios del índice original y
# priorizando los que se hacen en anillas.
#
# Criterio (Fitness Revolucionario):
# - Calentamiento RAMP, nunca estiramiento estático antes de entrenar:
#   1. Elevar: 60 s de cardio suave (cuerda, saltos, correr en el sitio).
#   2. Movilizar y activar: giros articulares, hombros (Preparación general
#      deltoides en anillas: ya recorre todo el rango, no se suman círculos de
#      deltoides), muñecas y escápulas (retracción y depresión).
#   3. Potenciar: lo que pide la sesión, en anillas y con poca carga (Aguante
#      isométrico con rotación externa, Plancha en anillas, cuelgue con agarre
#      falso). Skin the cat no: exige la extensión extrema del hombro que el
#      calentamiento prepara, y en el programa es trabajo principal. Esa
#      extensión va al final, sostenida (Estiramiento germano).
# - Movilidad al final: estiramientos con carga en anillas (Perro boca abajo, Perro
#   en T, Tríceps-deltoides, Germano, Superman), colgarse para descomprimir el
#   hombro y antebrazos para compensar el agarre falso. Respiración lenta.
#
# Plantillas por tipo de sesión (ver la asignación al final):
#   CAL01 / MOV01, MOV04  tren superior, empuje y tracción (fase 1)
#   CAL02 / MOV02, MOV08  piernas y core
#   CAL03 / MOV03         empuje (fondos, flexiones, tríceps)
#   CAL04 / MOV04         tracción (dominadas, remos, bíceps)
#   CAL05 / MOV01, MOV05, MOV06  habilidades: arqueros, inversiones, Skin the cat
#   CAL06 / MOV08         piernas a una pierna (pistolero, búlgara)
#   CAL07 / MOV05         cuerpo completo (circuitos)
#   CAL08 / MOV07         agarre falso y muscle-up
#   CAL09 / MOV08         piernas e isométricos invertidos (pino encogido)
#
# Formato: el de Unbreakable (ver backend/internal/mhimport/phases.go). "@NOMBRE"
# abre una plantilla; una línea por ejercicio: nombre | 60s o 10r [| xN];
# "xN:" ... "end" agrupa ejercicios que se repiten juntos N vueltas. Los
# unilaterales se hacen por ambos lados. Al final, "sesión: calentamiento movilidad".
